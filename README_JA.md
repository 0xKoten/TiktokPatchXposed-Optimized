## 🌟 最適化版の主な特徴 (What's New & Optimized)

最新版 TikTok (47.5+) に対応し、UIバグの修正、レイアウトの改善、利便性向上のための新機能を追加しました：

1. **上下の黒帯を完全解消 (フルスクリーン没入再生)**
   - 動画再生時の上下余白・黒帯を完全に除去し、シームレスな全画面表示を実現。
   - **すべてのフィードタブに対応**：「おすすめ」、「フォロー中」、「友達」、「コミュニティ」等のタブ切り替え時にも黒帯が再発しません。
   - 次の長尺動画の上部エッジが下部にチラ見えする現象（Peeking edge）を修正。

2. **Android 没入型フルスクリーン**
   - **ナビゲーションバーの非表示**：Android 仮想3ボタンおよびジェスチャーナビゲーションバー（白色の横バー）を隠し、画面の圧迫を防止。
   - **ステータスバーの非表示**：上部の時計、バッテリー残量、通知アイコンを非表示にして没入感を最大化。

3. **トップバー・ボトムバーの透明度カスタマイズ**
   - **上部ナビゲーションタブの透明度**（おすすめ、フォロー中、友達など）：0%〜100%まで無段階調整可能。
   - **下部ナビゲーションバーの透明度**（ホーム、友達、受信トレイ、プロフィール）：0%〜100%まで無段階調整可能。
   - 純正の「シンプル表示モード」終了時に背景が真っ黒にリセットされる問題を解消し、透明状態を常時維持。

4. **下部中央の「+」投稿ボタンの個別削除**
   - 中央の作成/投稿ボタンをワンタップで非表示に設定可能。
   - 残りの4つのタブ（ホーム、友達、受信トレイ、プロフィール）が画面幅に合わせて自動均等配置（各25%）され、整ったレイアウトを保ちます。

5. **シークバー操作時のUI再表示問題を修正**
   - 純正仕様では、プログレスバーを手動でドラッグした際に右側のアクションボタンや投稿者名・キャプションが強制表示される現象がありました。
   - 最適化版では描画イベントを適切にインターセプトし、シーク中および操作後も非表示・透明度設定を維持します。

6. **左上「LIVE」ボタンの個別カスタマイズ**
   - 純正モジュールの設定競合により、モジュールを有効化すると左上の「LIVE」アイコンが非表示になりボタンが無効化される問題を修正。
   - デフォルトでTikTok本来のLIVEアイコンおよびタップ機能を完全に保持。設定画面で非表示にするか自由に選択可能。

7. **専用の「非表示と透明度」設定ページ**
   - 複雑なサブメニューからUI非表示設定と透明度スライダーを独立させ、整理された2枚のカードUIで簡単に設定可能。

8. **独立したアプリアイコン＆モジュール内クレジット**
   - TikTok内を経由せず、ホーム画面のアプリアイコンから直接モジュール設定画面を起動可能。
   - モジュール設定内に原作者・元プロジェクトへの感謝クレジットを内蔵。

9. **多言語リアルタイム切り替え (14言語対応)**
   - 繁体中国語、簡体中国語、英語、日本語、韓国語、スペイン語、ドイツ語、フランス語、ロシア語など14言語をサポート。
   - モジュール内の設定画面から即時切り替え、またはシステム言語に追従可能。

## 🛠️ 原版のコア機能（継続サポート）

- 🚫 **完全広告ブロック**：フィード動画広告、起動時のスプラッシュ広告、検索広告をブロック。
- 📥 **透かしなし高画質ダウンロード**：最高画質動画の保存、音声単体保存、複数写真カルーセルの一括高画質保存。
- 🔄 **グローバル自動スクロール**：動画再生終了時に次の動画へ自動スクロール。
- 🎨 **アクセントカラー＆AMOLED漆黒モード**：TikTokのアクセントカラー変更、有機EL向けの省電力ピュアブラック背景。
- 🌐 **地域偽装＆ログイン不要ブラウズ**：地域制限を解除し、強制ログインポップアップを回避。
- 💬 **コメント自動翻訳＆ハッシュタグ制限解除**：外国語コメントの自動翻訳、投稿時のハッシュタグ数制限を解除。
- 🛡️ **ステルスモード**：ストーリーズ閲覧履歴やプロフィール訪問足跡を残さず閲覧。

## 📦 ビルド手順 (Building from Source)

### 動作環境
- **JDK**：OpenJDK 17 以上
- **Android SDK**：API 34+ (Build-Tools 34.0.0+)
- **Gradle**：8.7 (Gradle Wrapper 同梱)

### ビルド実行
同梱の Gradle Wrapper を使用してコンパイルします：

```bash
# Windows
.\gradlew.bat assembleRelease

# Linux / macOS
./gradlew assembleRelease
```

生成された APK ファイルのパス：
`app/build/outputs/apk/release/app-release.apk`
