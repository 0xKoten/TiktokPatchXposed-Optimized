## 🌟 优化版特色功能 (What's New & Optimized)

本优化版针对最新版 TikTok (47.5+) 进行全方位界面修复、版面优化与全新功能扩展：

1. **彻底消除上下黑边 (全屏沉浸播放)**
   - 消除视频播放时的上下留白与黑边，让短视频全屏无缝铺满。
   - **全面适配全 Feed 分页**：包括“推荐”、“关注中”、“好友”、“社群”等所有页面，切换分页时黑边不复发。
   - 修复下一个较长视频顶部边缘在底部露出（Peeking edge）的问题。

2. **Android 沉浸式全屏**
   - **隐藏系统导航栏**：支持隐藏 Android 虚拟三键及底部白色手势小横条（Gesture Pill），防止推挤或遮挡画面。
   - **隐藏系统状态栏**：支持隐藏顶部电量、时间及通知图标，带来极致视觉体验。

3. **顶栏与底栏自定义透明度**
   - **顶部导航标签透明度**（推荐、关注中、朋友等）：支持 0% 至 100% 任意平滑调节。
   - **底部导航栏透明度**（首页、朋友、收件箱、个人资料）：支持 0% 至 100% 任意平滑调节。
   - 解决原生“简易显示（清屏模式）”退出时背景重置回纯黑的问题，常驻保持透明。

4. **独立移除底栏中间“+”发布按钮**
   - 可一键删除中间的创建/发布按钮。
   - 剩余 4 个标签（首页、朋友、收件箱、个人资料）自动重新均分屏幕宽度（各占 25%），版面平衡协调。

5. **修复拖动视频进度条时 UI 复发问题**
   - 原版在手动拖动底部进度条时，右侧按钮（头像、点赞、评论、分享）与作者文案会被官方逻辑重置显现。
   - 优化版通过 `OnPreDraw` 与属性拦截，确保拖动进度条期间及释放后，隐藏与透明度设定持续生效。

6. **自订顶部左上角 LIVE 直播按钮**
   - 原版模块因设定冲突，会导致开启模块时首页左上角 LIVE 直播图标被强制隐藏且按钮失效。
   - 优化版彻底解耦修复，默认完整保留 TikTok 原生 LIVE 入口与点击功能；并在设定内提供独立开关，方便自由选择是否隐藏。

7. **独立“隐藏与透明度”专属设定页**
   - 将界面隐藏选项与透明度滑杆从复杂的次级菜单中抽离，独立成整齐干净的双卡片界面（隐藏设定 / 透明度调节）。

8. **独立 Launcher 桌面入口与模块内感谢名单**
   - 桌面提供独立图标直接开启模块设定，无需依赖 TikTok 内部路径。
   - 设定界面内置感谢名单与原项目链接。

9. **多语言自由切换 (14 种语言支持)**
   - 支持正体中文、简体中文、English、日本語、한국어、Español、Deutsch、Français、Русский 等 14 种语言。
   - 模块内部提供独立语言切换页面，支持即时切换或自动跟随系统。

## 🛠️ 原版经典核心特性保留

- 🚫 **全面阻挡广告**：Feed 视频流广告、启动开屏广告、搜索广告全面净化。
- 📥 **无水印与全画质下载**：强制解锁原画下载、音频单独保存、轮播图集原图批量下载。
- 🔄 **全局自动滚动**：视频播放结束后自动滑动至下一条。
- 🎨 **主题强调色与 AMOLED 纯黑模式**：替换 TikTok 红色主色调，纯黑 AMOLED 背景更省电。
- 🌐 **多国区域伪装与免登录浏览**：解锁区域内容限制，绕过强制登录弹窗。
- 💬 **评论自动翻译与无限制标签**：评论自动翻译，解除发布视频标签数量限制。
- 🛡️ **隐身模式**：隐藏观看限时动态记录、隐藏个人主页访问记录。

## 📦 编译指南 (Building from Source)

### 环境需求
- **JDK**：OpenJDK 17 或更高
- **Android SDK**：API 34+ (Build-Tools 34.0.0+)
- **Gradle**：8.7 (已包含 Gradle Wrapper)

### 本地编译
使用项目内置的 Gradle Wrapper 进行编译：

```bash
# Windows
.\gradlew.bat assembleRelease

# Linux / macOS
./gradlew assembleRelease
```

编译生成的 APK 位于：
`app/build/outputs/apk/release/app-release.apk`
