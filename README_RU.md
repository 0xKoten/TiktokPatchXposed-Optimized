## 🌟 Что нового и оптимизировано (What's New & Optimized)

Оптимизированная версия включает комплексные исправления интерфейса, переработку макета и новые функции для актуальных версий TikTok (47.5+):

1. **Полное устранение черных полос (Полноэкранный режим)**
   - Убирает верхние и нижние черные полосы для истинного полноэкранного воспроизведения видео.
   - **Полная совместимость со всеми вкладками ленты**: «Рекомендации», «Подписки», «Друзья» и др. Черные полосы не возвращаются при переключении вкладок.
   - Исправлена проблема с выглядывающим верхним краем следующего длинного видео (Peeking edge).

2. **Полноэкранный режим Android (Immersive Mode)**
   - **Скрытие панели навигации**: Скрывает 3 экранные кнопки навигации и белую полоску жестов, предотвращая смещение контента.
   - **Скрытие строки состояния (Status Bar)**: Скрывает часы, уровень заряда батареи и значки уведомлений.

3. **Настройка прозрачности верхней и нижней панелей**
   - **Прозрачность верхних вкладок навигации**: Плавная регулировка от 0% до 100%.
   - **Прозрачность нижней панели**: Плавная регулировка от 0% до 100%.
   - Устраняет сброс фона в сплошной черный цвет при выходе из режима «Чистый дисплей».

4. **Отдельное удаление центральной кнопки «+» (Создать)**
   - Возможность скрыть центральную кнопку публикации в один клик.
   - Оставшиеся 4 вкладки автоматически равномерно распределяются по ширине экрана (по 25% каждая).

5. **Исправление возврата интерфейса при перемотке видео**
   - В оригинале при ручной перемотке видео ползунком боковые кнопки (лайк, комменты, поделиться) и автор принудительно отображались.
   - В оптимизированной версии настройки скрытия и прозрачности продолжают работать во время и после перемотки.

6. **Настройка кнопки LIVE в левом верхнем углу**
   - Исправлен конфликт оригинального модуля, из-за которого при включении пропадала кнопка прямых эфиров LIVE.
   - По умолчанию сохраняется оригинальный вид и функционал кнопки LIVE, а в настройках модуля добавлен отдельный переключатель для её скрытия.

7. **Отдельная страница настроек «Скрытие и Прозрачность»**
   - Настройки скрытия элементов и слайдеры прозрачности вынесены из вложенных меню в удобный интерфейс с двумя карточками.

8. **Иконка в меню приложений и список благодарностей**
   - Добавлена отдельная иконка на рабочем столе для быстрого открытия настроек модуля без необходимости запускать TikTok.
   - Встроенный раздел благодарностей со ссылкой на оригинальный проект.

9. **Поддержка 14 языков в интерфейсе**
   - Встроенный переключатель языков: русский, традиционный китайский, упрощенный китайский, английский, японский, корейский, испанский, немецкий, французский и др.
   - Мгновенное переключение языка в настройках или автоматическое следование системному языку.

## 🛠️ Сохраненные ключевые функции оригинала

- 🚫 **Блокировка рекламы**: Удаление рекламы в ленте, рекламы при запуске и в поиске.
- 📥 **Скачивание без водяных знаков**: Загрузка видео в максимальном качестве, отдельное сохранение аудиодорожек и фото-каруселей в полном разрешении.
- 🔄 **Автопрокрутка ленты**: Автоматический переход к следующему видео по завершении текущего.
- 🎨 **Акцентный цвет и чистый AMOLED-черный**: Настройка акцентного цвета и чистый черный фон для экономии заряда батареи.
- 🌐 **Смена региона и обход авторизации**: Доступ к контенту других стран и пропуск окна обязательного входа.
- 💬 **Автоперевод комментариев и неограниченные хэштеги**: Автоматический перевод иностранных комментариев и снятие ограничений на количество хэштегов.
- 🛡️ **Режим невидимки (Ghost Mode)**: Просмотр историй и профилей без оставления следов.

## 📦 Сборка из исходников (Building from Source)

### Требования
- **JDK**: OpenJDK 17 или новее
- **Android SDK**: API 34+ (Build-Tools 34.0.0+)
- **Gradle**: 8.7 (Gradle Wrapper включен в репозиторий)

### Команды сборки
```bash
# Windows
.\gradlew.bat assembleRelease

# Linux / macOS
./gradlew assembleRelease
```

Собранный APK-файл будет находиться по пути:
`app/build/outputs/apk/release/app-release.apk`
